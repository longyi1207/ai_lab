## 0. 先说结论：这一章要讲明白的一件事

π 是无理数，写不成分数。但可以用分数**逼近**它：3、22/7、355/113……分母越大，逼近越准，这很平常。真正的问题是：

> **跟分母的大小相比，π 能被逼近得"多好"？**

这一章要讲清楚的是一条链：

> 任何无理数都能被逼近到"误差 ≈ 1/q²"（Dirichlet，人人都有）⟹ 问题变成"能不能**比 1/q² 好得多**，而且好无穷多次" ⟹ 用一个数 μ（无理性指数）衡量这种"超常逼近"的能力 ⟹ 几乎所有实数 μ = 2，但对**具体的** π，70 年来只能证明 μ ≤ 7.1。

OpenAI 声称证明了 μ(π) = 2，也就是说：π 在这件事上和"随便挑的一个实数"一样普通，不存在无穷多个"好得离谱"的分数逼近。顺带解决了一个流行谜题：Flint Hills 级数 Σ 1/(n³ sin²n) 收敛。

读完这一章，你应该能用自己的话讲出：
- "被分数逼近得多好"怎么精确地度量，为什么基准线是 1/q²；
- 为什么"几乎所有数 μ = 2"很容易证，而"π 的 μ = 2"极难证；
- OpenAI 的证明在用什么套路（一句话："一个非零整数至少是 1"），以及它被核实到了什么程度；
- 这个结果**不**意味着什么（不是超越性、不是"正规数"、不是"连分数有界"）。

## 1. 用分数逼近 π：从 3 到 355/113

### 1.1 一张表

π = 3.14159265358979…。历史上著名的几个分数：

| 分数 | 来历 | 误差 \|π − p/q\| | 1/q² | q² × 误差 |
|---|---|---|---|---|
| 3/1 | 古代 | 1.42×10⁻¹ | 1 | 0.142 |
| 314/100 | 小数截断 | 1.59×10⁻³ | 1×10⁻⁴ | 15.9 |
| 22/7 | 阿基米德"约率" | 1.26×10⁻³ | 2.04×10⁻² | 0.062 |
| 333/106 | | 8.32×10⁻⁵ | 8.90×10⁻⁵ | 0.935 |
| 355/113 | 祖冲之"密率"（5 世纪） | 2.67×10⁻⁷ | 7.83×10⁻⁵ | **0.0034** |
| 103993/33102 | | 5.78×10⁻¹⁰ | 9.13×10⁻¹⁰ | 0.633 |

（脚本实算。）

### 1.2 为什么要除以"分母成本"

误差变小本身不稀奇：分母允许到 10⁶，你随便取 3141593/1000000 也能把误差压到 10⁻⁷ 左右。所以只看误差是不公平的，要看**相对于分母大小**的误差。

看 314/100 和 22/7：两者误差差不多（都约 10⁻³），但 22/7 只用了分母 7，而 314/100 用了分母 100。22/7 "性价比"高得多。

一个自然的度量是：**误差相当于分母的几次方的倒数？** 如果 |π − p/q| ≈ q^(−ν)，我们就说这个逼近的"有效指数"是 ν。ν 越大，逼近越"超常"。

- 314/100：误差 ≈ 100^(−1.4)，ν ≈ 1.4。小数截断大约只有 ν ≈ 1 的水平（误差 ~ 1/q）。
- 22/7：ν ≈ 3.43（脚本实算）。
- 355/113：ν ≈ 3.20（脚本实算）。这就是"密率"神奇的地方：用三位数的分母，得到了约 10⁻⁷ 的精度（小数点后 6 位全对）。

表的最后一列 q² × 误差 是另一个角度：如果它 < 1，说明误差比 1/q² 还小。355/113 的这一列是 0.0034，也就是比 1/q² 好了约 **290 倍**。

## 2. 连分数：寻找"最佳逼近"的机器

上表里的 3、22/7、333/106、355/113 不是凑出来的，它们是一台机器的输出。这台机器叫**连分数**（continued fraction）。

### 2.1 算法：取整、取倒数、重复

对一个数 x：
1. 写下整数部分 a₀，剩下小数部分 r。
2. 把 r 取倒数 1/r，再写下它的整数部分 a₁，剩下新的小数部分。
3. 重复。

拿 π 手算前两步：
- π = 3 + 0.14159…，所以 a₀ = 3。
- 1/0.14159… = 7.0625…，所以 a₁ = 7。
- 1/0.0625… = 15.996…，所以 a₂ = 15。

继续下去（脚本实算）：

```
π = [3; 7, 15, 1, 292, 1, 1, 1, 2, 1, 3, 1, 14, 2, 1, 1, 2, 2, 2, 2, …]
```

意思是 π = 3 + 1/(7 + 1/(15 + 1/(1 + 1/(292 + …))))。

### 2.2 截断 = 好分数

在某一位截断，就得到一个分数，叫**渐近分数**（convergent）：
- 截在 [3] → 3
- 截在 [3; 7] → 3 + 1/7 = 22/7
- 截在 [3; 7, 15] → 333/106
- 截在 [3; 7, 15, 1] → 355/113
- 截在 [3; 7, 15, 1, 292] → 103993/33102

经典定理（Lagrange 等，18 世纪）：渐近分数是"最佳逼近"，分母不超过 q 的所有分数里，没有谁比它更接近 x。

### 2.3 下一个数字越大，当前这个分数越准

这是本章最有用的一条经验规律：

> 渐近分数 p/q 的误差约等于 1 / (a_next × q²)，其中 a_next 是连分数里**紧跟在截断处后面**的那个数（叫"部分商"）。

- 22/7 后面紧跟 15：误差 ≈ 1/(15 × 49) ≈ 1.4×10⁻³，实际 1.26×10⁻³。
- 355/113 后面紧跟 **292**：误差 ≈ 1/(292 × 12769) ≈ 2.7×10⁻⁷，实际 2.67×10⁻⁷。
- 333/106 后面紧跟 1：误差 ≈ 1/(1 × 106²)，和 1/q² 同一量级，一点也不"超常"（q² × 误差 = 0.935）。

所以，**问"π 能否被超常地逼近"，等价于问"π 的连分数里会不会出现特别巨大的部分商"**。292 是一次，以后还会不会有更离谱的？

### 2.4 对照组：几个"长相规整"的数

| 数 | 连分数（脚本实算） | 规律 |
|---|---|---|
| 黄金比 φ = (1+√5)/2 | [1; 1, 1, 1, 1, …] | 全是 1，最难逼近的数 |
| √2 | [1; 2, 2, 2, 2, …] | 永远是 2 |
| e | [2; 1, 2, 1, 1, 4, 1, 1, 6, 1, 1, 8, …] | 1, 1, 2k 的模式，缓慢增长 |
| π | [3; 7, 15, 1, 292, 1, 1, 1, 2, …] | **没有已知规律** |

对 √2、e 这样有规律的数，部分商的大小一眼可见，所以"能被逼近得多好"可以直接算出来。π 的连分数**没有任何已知规律**，这正是难点的根源：你没法盯着它的连分数去证明"以后永远不会出现一个超级大的数"。

## 3. Dirichlet 定理：指数 2 是人人都有的

### 3.1 结论

> **Dirichlet 逼近定理（1842）**：对任何无理数 x，有无穷多个分数 p/q 满足 |x − p/q| < 1/q²。

也就是说，有效指数 2 是"免费的"，任何无理数都能做到。这就是为什么基准线是 1/q² 而不是别的。

### 3.2 证明：抽屉原理，可以手算

取一个整数 Q，比如 Q = 10。看 0·π, 1·π, 2·π, …, 10·π 这 11 个数的**小数部分**（脚本实算）：

| q | qπ 的小数部分 |
|---|---|
| 0 | 0.000 |
| 1 | 0.142 |
| 2 | 0.283 |
| 3 | 0.425 |
| 4 | 0.566 |
| 5 | 0.708 |
| 6 | 0.850 |
| 7 | 0.991 |
| 8 | 0.133 |
| 9 | 0.274 |
| 10 | 0.416 |

把 [0, 1) 切成 10 个长度 0.1 的抽屉。11 个数放进 10 个抽屉，**至少有两个在同一个抽屉里**。看表：q = 1（0.142）和 q = 8（0.133）都在 [0.1, 0.2) 里。

两者相减：8π − 1π = 7π，小数部分只差 0.009。这说明 7π 离某个整数很近：7π ≈ 21.991，离 22 只差 0.0089。于是

```
|7π − 22| < 1/10   ⟹   |π − 22/7| < 1/(7 × 10) ≤ 1/7²
```

一般地，Q 个抽屉、Q+1 个数，总能找到 q ≤ Q 使 |qx − p| < 1/Q，于是 |x − p/q| < 1/(qQ) ≤ 1/q²。让 Q 越来越大，就能得到无穷多个这样的分数。证毕。

【检查 3】在上表里再找一对落在同一个抽屉的 q。它们的差是多少？给出的是哪个分数？

### 3.3 能不能比 1/q² 更好？

脚本实算：在分母 2 ≤ q ≤ 100,000 的所有既约分数里，数一数满足 |π − p/q| < q^(−ν) 的有几个：

| ν | 满足的分数个数 | 它们的分母 |
|---|---|---|
| 2 | 8 | 6, 7, 106, 113, 33102, 33215, 66317, 99532 |
| 2.2 | 2 | 7, 113 |
| 2.5 | 2 | 7, 113 |
| 3 | 2 | 7, 113 |

ν = 2 时个数一直在增加（Dirichlet 保证它无穷多）。ν 只比 2 大一点时还剩几个（脚本实算：分母 6、106、33102、33215、66317、99532 的有效指数在 2.01–2.11 之间）；ν ≥ 2.2 时，10 万以内只剩 22/7 和 355/113 两个"早期奇迹"。

**μ(π) = 2 说的就是**：对任何 ν > 2（哪怕 2.0001），这样的分数只有**有限多个**。早期可以有几个奇迹，但奇迹不能无穷无尽地出现。

## 4. 无理性指数 μ：定义和一个"动物园"

### 4.1 定义

> **无理性指数**（irrationality exponent，也叫 irrationality measure）
> μ(x) = 所有满足"|x − p/q| < q^(−ν) 有无穷多个解"的 ν 的上确界。

白话：μ(x) 是 x 能被"无穷多次超常逼近"的最高指数。μ 越大，x 越容易被分数逼近得很好，在这个意义上越"接近有理数"。

连分数版本（标准结论）：μ(x) = 2 + limsup (ln a_{n+1} / ln q_n)。也就是说，**μ = 2 当且仅当部分商 a_{n+1} 的增长比 q_n 的任何正次方都慢。**

脚本实算一个例子：π 连分数前 1000 项里最大的部分商是 20776（第 431 项），它前面那个渐近分数的分母有 216 位。这次逼近的有效指数只有 **2.020**。分母这么大，即使出现了一个两万多的部分商，对指数的贡献也微不足道。相比之下，355/113 的有效指数是 3.20，那是"分母很小时运气好"。

### 4.2 动物园

| 数 | μ | 谁证明的 |
|---|---|---|
| 有理数 | 1 | 平凡 |
| 任何无理数 | ≥ 2 | Dirichlet 1842（第 3 节） |
| √2 等二次无理数 | 2 | Liouville 型论证，见 4.3 |
| 任何代数无理数（如 ∛2） | 2 | **Roth 1955**，获 1958 年 Fields 奖 |
| e | 2 | 由它规律的连分数直接算出 |
| 几乎所有实数（勒贝格测度意义） | 2 | Khinchin（1920 年代），见 4.5 |
| Liouville 数 Σ 10^(−k!) | ∞ | Liouville 19 世纪中叶 |
| π | 已知 ≤ 7.10；**OpenAI 声称 = 2** | 见第 5、7 节 |

### 4.3 一个可以手算的证明：为什么 √2 不能被超常逼近

这个小证明里藏着整章（包括 OpenAI 证明）的核心套路，值得慢慢看。

对任何分数 p/q，看整数 p² − 2q²：
- 它**不是 0**（因为 √2 是无理数）。
- 它是**整数**。
- 所以 |p² − 2q²| **≥ 1**。

另一方面，p² − 2q² = q² (p/q − √2)(p/q + √2)。所以

```
|√2 − p/q| = |p² − 2q²| / (q² · (p/q + √2)) ≥ 1 / (q² · (p/q + √2)) ≈ 1/(2.83 q²)
```

误差永远不会小于大约 0.35/q²，所以有效指数超不过 2，μ(√2) = 2。

手算 p/q = 7/5：p² − 2q² = 49 − 50 = −1，绝对值恰好是 1。预测误差 = 1/(25 × (1.4 + 1.41421)) = 0.01421，实际 |1.41421 − 1.4| = 0.01421。（脚本还验证了：√2 的渐近分数的 q² × 误差 一直稳定在 0.35 左右。）

**核心套路**：
> 构造一个和逼近有关的量。**算术上**：它是非零整数，所以 ≥ 1。**分析上**：如果逼近太好，它会 < 1。两者矛盾。

记住这句话，第 7 节会再遇到它。

### 4.4 Liouville 数：μ = ∞ 的怪物

L = Σ 10^(−k!) = 0.110001000000000000000001000…（1 出现在小数点后第 1, 2, 6, 24, 120, … 位）。

把它在某个 1 之后截断，得到的分数误差极小（脚本实算）：
- 截到第 2 位：q = 10²，误差 ≈ 10⁻⁶ = q^(−3)
- 截到第 6 位：q = 10⁶，误差 ≈ 10⁻²⁴ = q^(−4)
- 截到第 24 位：q = 10²⁴，误差 ≈ 10⁻¹²⁰ = q^(−5)

有效指数 3, 4, 5, … 无限增长，所以 μ(L) = ∞。Liouville 用这类数构造出了历史上第一批**被证明是超越数**的数（因为代数数的 μ 是有限的，μ = ∞ 的数就一定不是代数数）。

**这一点对理解难度至关重要**：Liouville 数是超越数，μ = ∞。π 也是超越数（Lindemann 1882）。所以**"π 是超越数"这个事实本身对 μ(π) 毫无帮助**，任何只用到"π 是超越数"的论证都会被 Liouville 数推翻。要证 μ(π) = 2，必须用到 π 独有的结构。

### 4.5 为什么"几乎所有数 μ = 2"很容易证

在 [0, 1] 里随机扔一个点 x。对固定的 q，"x 离某个 p/q 小于 q^(−ν)"的区域，总长度大约是 q 个小区间 × 每个长 2q^(−ν) = 2q^(1−ν)。

把所有 q 加起来：Σ 2q^(1−ν)。当 ν > 2 时，指数 1 − ν < −1，这个和**收敛**（就是第 1 章的 ζ(ν−1) 乘以 2，s > 1 时 ζ(s) 有限）。概率论里有个 Borel–Cantelli 引理：如果一串事件的概率之和有限，那么几乎必然只有有限多个事件发生。所以几乎每个 x 都只有有限多个指数 ν 的超常逼近，μ(x) ≤ ν。ν 可以任意接近 2，于是几乎所有 x 都有 μ = 2。

**这个论证完全没法用在 π 上**：它说的是"一个随机的数"，而 π 是一个特定的数。就像"几乎所有人都不是左撇子"不能告诉你某个具体的人是不是左撇子。这就是这类问题的典型形状：**典型行为一眼可知，具体实例极难证明**（"π 是正规数"也是这种形状，至今未解）。

### 5.1 时间线

| 1974 | Mignotte | 21（所有分母）/ 20（最终） | Bull. SMF Mém. 37 |
| 1993 | Hata | 8.01604539… | Acta Arith. 63 |
| 2008 | Salikhov | 7.606308… | Russ. Math. Surveys 63(3) |
| 2020 | Zeilberger–Zudilin | 7.103205334137… | Moscow J. Comb. Number Theory 9(4)；arXiv:1912.06345 |
| 2026-09 | Bai（预印本） | 7.101862832357 | arXiv:2609.11276 ⚠ 未经同行评审 |
| 2026-09-24 | OpenAI（声称） | **= 2** | 本章第 7 节 |

注意最后两步之间的跨度：前 70 年是 42 → 7.10，每一步都是大量精细工作；然后一步跳到 2，而且是**精确值**，不是又一个上界。

### 5.2 旧方法的天花板

此前所有上界都来自同一个框架（Zudilin 的综述 arXiv:math/0404523 讲得很清楚）：

1. 构造一列整数系数的"线性形式" aₙπ − bₙ，要求它**很小但不是 0**。通常用精心设计的积分来造。
2. 两个量互相拉扯：
   - 线性形式衰减得多快（越快越好）；
   - 系数 aₙ 增长得多快（越慢越好）。为了让系数是整数，往往要乘上 lcm(1, 2, …, n) 这样的大数来"清分母"，这个代价很大。
3. 标准引理：如果衰减率是 e^(−βn)、系数增长是 e^(αn)，就得到 μ ≤ 1 + α/β。

要得到 μ = 2，需要 α 和 β 几乎相等，也就是"清分母的代价"几乎为零。对 π 已知的所有积分构造，这个比值都离 1 很远。Zeilberger–Zudilin 那一代工作是在这个框架里拧螺丝（优化积分的参数），每次只能挪一点点。

### 5.3 为什么 Roth 的方法不能直接用

Roth 定理对所有代数数给出 μ = 2，方法是**多变量**的：同时取好几个分母相差极大的逼近 p₁/q₁, p₂/q₂, …，构造一个多变量多项式，用第 4.3 节那种"非零整数 ≥ 1"的套路导出矛盾。

但 Roth 的证明本质上用到 x 满足一个整系数多项式方程（x 是代数数）。π 不是代数数，所以没有那个方程可用。而第 4.4 节说过，你也不能只用"π 是超越数"。OpenAI 的推理摘要里恰好记录了模型撞上这堵墙的一刻（原文逐字）：

> "Wait this would work for any transcend, contradiction with Liouville. Examine."

意思是：它发现自己的某个论证如果成立，会对**所有超越数**成立，但 Liouville 数是反例，所以论证一定有漏洞。

## 6. 一个具体后果：Flint Hills 级数

### 6.1 级数是什么

```
Σ 1/(n³ sin² n) = 1/(1³ sin²1) + 1/(2³ sin²2) + 1/(3³ sin²3) + …     （n 是弧度）
```

问题：它收敛吗？这个问题由 Pickover 推广普及，Alekseyev 2011（arXiv:1104.5100）做了系统讨论，一直没解决。

### 6.2 为什么它和 π 的逼近有关

分母里有 sin n。当整数 n 非常接近 π 的某个整数倍 kπ 时，sin n 非常小，这一项就会爆大。而"n ≈ kπ"就是"n/k ≈ π"，也就是 **n/k 是 π 的一个好的分数逼近**。

脚本实算部分和：

| n | 这一项 | 部分和 |
|---|---|---|
| 1 | 1.412 | 1.412 |
| 3 | 1.860 | 3.423 |
| 21 | 0.00015 | 3.555 |
| **22**（22/7） | **1.199** | 4.754 |
| 354 | 3.2×10⁻⁸ | 4.807 |
| **355**（355/113） | **24.60** | 29.406 |
| 1,000 | 1.5×10⁻⁹ | 30.175 |
| 103,993（103993/33102） | 2.4×10⁻⁶ | 30.3145 |
| 1,000,000 | 8.2×10⁻¹⁸ | 30.3145 |

整条曲线是阶梯形：平时几乎不动，每当 n 撞上 π 的一个超常好逼近的分子，就跳一下。n = 355 那一项单独贡献了 24.6，是前 100 万项总和的 81%。

【检查 4】解释 n = 355 那一项为什么约等于 24.6。（提示：sin(355) = sin(355 − 113π)，而 355 − 113π ≈ 3.01×10⁻⁵；sin 很小的角 ≈ 角本身。）

### 6.3 收敛与否完全由 μ(π) 决定

- 如果 π 有无穷多个"太好"的逼近，就会有无穷多次足够大的跳跃，级数发散。
- 如果超常逼近足够稀少，跳跃加起来有限，级数收敛。

两个已发表的判据把它精确地连到 μ(π)：
- Alekseyev 2011：如果级数收敛，那么 μ(π) ≤ 5/2。
- Meiburg 2022（arXiv:2208.13356）：如果 μ(π) < 5/2，那么级数收敛。

所以只要证明 μ(π) < 2.5，问题就解决了。但已知最好的是 7.10，差得远。OpenAI 的推理摘要显示，模型一开始的目标正是 μ < 5/2，后来才发现可以一路推到 2（见第 7.3 节）。

论文 §5 还自己给了一个短证明（把整数 n 按最近的 qπ 分组，用 |sin n| ≥ (2/π)·|n − qπ| 控制每组），并推出更一般的结论：Σ 1/(nᵃ |sin n|ᵇ) 收敛，当且仅当 a > max{1, b}。

## 7. OpenAI 声称了什么

### 7.1 主结果

论文 *The irrationality exponent of π is 2*（OpenAI，2026-09-24，23 页）的摘要：

> "We prove the conjecture that the irrationality exponent of π is 2. As a consequence, the classical Flint–Hills series Σ_{n≥1} 1/(n³ sin² n) converges, with angles in radians."

主定理（Theorem 1.1）的精确说法：

> 对每个实数 ν > 2，存在整数 Q(ν)，使得对一切整数 p 和一切 q ≥ Q(ν)，都有 |π − p/q| ≥ q^(−ν)。

论文自己特别交代了三点（都很重要）：
1. 不要求 p/q 是既约分数。
2. **Q(ν) 不可有效计算**："the argument does not give it effectively"。也就是说，它证明了"从某个分母开始，再也没有指数 ν 的超常逼近"，但不告诉你从哪里开始。
3. **μ = 2 不等于"部分商有界"**："an exponent of 2 is different from a uniform positive lower bound of the form c/q², or equivalently from bounded continued-fraction partial quotients"。后者（π 的连分数部分商是否有界）仍未解决。

论文还记录了同领域的其他声明：Mantzakouras 与 López Zapata 的 Flint Hills 收敛声明已于 2026-09 撤回；Carella 声称 μ(π) = 2 以及更强的"部分商有界"，OpenAI 论文在脚注里指出其更强结论的证明有一处符号错误（这是 OpenAI 一方的说法 ⚠，没有第三方确认）。

论文说 Waldschmidt 在 *Open Diophantine problems*（Moscow Math. J. 4(1), 2004, p. 265）里把这个结论记录为猜想。

### 7.2 方法的直觉（只读了引言和 §5，以下是简化版）

回忆第 4.3 节的套路："非零整数 ≥ 1，但逼近太好会让它 < 1"。OpenAI 的证明是这个套路的一个非常重型的版本。

1. **反证**。固定一个 ν > 2，假设 π 有无穷多个指数 ν 的超常逼近。
2. **挑几个，分母拉得很开**。从这无穷多个里挑出 m 个，分母一个比一个大得多：q₁ ≪ q₂ ≪ … ≪ q_m。这一步和 Roth 一样（多变量、分母分离）。
3. **用上 π 独有的结构：它是指数函数的周期**。e^(2πi) = 1，所以 2πi·j 是指数函数的"周期"，也是对数函数多值性的来源。作者把超常逼近 pᵢ/qᵢ 变成 2i·j·pᵢ/qᵢ，这些数逼近真正的周期 2πi·j。这一步回答了第 4.4 节的问题：证明用的不是"π 是超越数"，而是"π 和 exp/log 的这一具体关系"，Liouville 数没有这种结构。
4. **构造一个大行列式**。考虑多变量多项式 P(Y, X₁, …, X_m)，沿着"对数曲线" Y = 1 + t, Xᵢ = cᵢ + log(1 + t) 展开，取泰勒系数，排成一个大矩阵。论文第 2 节的新定理（"分离权重插值"，用到代数几何里的 blowup、ampleness 等工具）保证这个矩阵满秩，于是能挑出一个**非零**行列式。
5. **算术下界**。矩阵元素都在 ℚ(i) 里（形如 a + bi，a、b 是分数）。乘掉分母后，行列式是一个非零的"高斯整数"，绝对值 ≥ 1。
6. **分析上界**。把近似值 2i·j·pᵢ/qᵢ 换回真正的周期 2πi·j，很多行会变成同一些函数的泰勒系数，彼此几乎相关，行列式会因此大幅抵消（论文称为"quadratic saving"）；剩下的项则带有极小的逼近误差 |π − pᵢ/qᵢ| 作为因子。结果：行列式的绝对值 < 1。
7. **矛盾**。≥ 1 且 < 1 不可能，所以假设错误，指数 ν 的超常逼近只有有限多个。

为什么能推到任意 ν > 2：维数 m（挑几个逼近）可以随 ν 增大。维数越高，"抵消节约"增长得越快，最终压过任何 ν > 2 带来的代价。
为什么 Q(ν) 算不出来：论证从"假设有无穷多个"出发，挑出的逼近没有具体位置，这和 Roth 定理的"不可有效性"是同一个来源。

### 7.3 推理摘要：AI 是怎么走到这一步的

OpenAI 公开了一份 42 页的"删节版思维链摘要"（`reasoning_traces/irrationality-exponent-of-pi.pdf`）。脚本读过全文目录，结构如下：

- **Part I（第 1–44 节）**：目标只是 Flint Hills 需要的 μ < 5/2。模型试过 BBP 公式、模形式、Padé 逼近、Chudnovsky 级数、p-adic 对数、椭圆函数等几十条路线，反复撞上它自己反复称为"高度 vs 分母代价"（height barrier）的那堵墙，也就是第 5.2 节说的"清分母的代价"。中途多次参考 OpenAI 自己的 Catalan 常数手稿里的行列式思路。最后用加权插值行列式拿到 μ ≤ 62/25 = 2.48，从而 Flint Hills 收敛。第 32–44 节的标题几乎都是 "audit"、"stress-testing"，即反复自查这一步。
- **Part II（第 45 节）**："takes the earlier report's interpolation-and-determinant technique as a starting point and claims exponent two, explicitly without assuming the earlier approximation bound"。在同一技术上调参数、升维数，推到 μ = 2。

这份文件本身就是一个很好的研究过程案例：目标设定得很保守（2.5），结果在审计中发现技术本身的上限是 2。

## 8. 它被核实到什么程度

### 8.1 Lean 陈述：你可以自己读懂

repo 里的"挑战陈述"文件 `lean/ComparatorChallenges/PiExponent.lean`（只 import Mathlib）：

```lean
theorem main :
  (∀ ν : ℝ, 2 < ν → ∃ Q : ℤ, 2 ≤ Q ∧
    ∀ p q : ℤ, Q ≤ q →
      (q : ℝ) ^ (-ν) ≤ |Real.pi - (p : ℝ) / (q : ℝ)|) ∧
  sSup {ν : ℝ | 0 < ν ∧
    Set.Infinite {r : ℚ | 2 ≤ r.den ∧
      0 < |Real.pi - (r : ℝ)| ∧
      |Real.pi - (r : ℝ)| < (r.den : ℝ) ^ (-ν)}} = 2
```

逐段翻译：
- **第一部分**（`∧` 之前）：
  - `∀ ν : ℝ, 2 < ν →`：对任何大于 2 的实数 ν，
  - `∃ Q : ℤ, 2 ≤ Q ∧`：存在一个整数门槛 Q ≥ 2，
  - `∀ p q : ℤ, Q ≤ q →`：对所有整数 p 和所有 ≥ Q 的整数 q，
  - `(q : ℝ) ^ (-ν) ≤ |Real.pi - p/q|`：π 和 p/q 的距离至少是 q^(−ν)。
  - 这正是 Theorem 1.1。注意它只说"存在 Q"，不给出 Q，和论文的"不可有效"一致。
- **第二部分**（`∧` 之后）：
  - `{r : ℚ | 2 ≤ r.den ∧ 0 < |π − r| ∧ |π − r| < r.den^(−ν)}`：所有分母 ≥ 2、满足指数 ν 超常逼近的有理数的集合（Lean 的 ℚ 自动是既约分数，`r.den` 是分母）。
  - `Set.Infinite …`：这个集合是无穷集。
  - `sSup {ν | 0 < ν ∧ …} = 2`：所有"有无穷多解"的 ν 的上确界等于 2。这就是第 4.1 节 μ 的定义，逐字对应。

两个值得注意的细节：
- 陈述里**只用了 Mathlib 的标准定义**（`Real.pi`、`sSup`、`Set.Infinite`、`ℚ`），没有 OpenAI 自己定义的概念。这比"用自定义定义写陈述"可信得多。
- Lean 里 `sSup` 有一个"垃圾值"约定：对空集或无上界的集合，它返回 0。这里结论是 = 2 而不是 = 0，所以不会落进这个陷阱。

### 8.2 证明本身（脚本在本地 sparse clone 上统计，snapshot fd4aeeb）

- 解答目录 `lean/OAI/NumberTheory/PiExponent/`：**869 个 .lean 文件，94,948 行**。

## 9. 如果为真，意味着什么（以及不意味着什么）

### 9.1 对数学：意味着什么

1. **一个被正式记录的猜想被解决**：π 在逼近性质上是"典型的"，和几乎所有实数一样。70 年的上界竞赛（42 → 7.10）以"精确值"的方式结束。
2. **Flint Hills 级数收敛**，以及更一般的 Σ 1/(nᵃ |sin n|ᵇ) 的完整收敛判据。
3. **方法可能比结论更重要**。"沿对数曲线的分离权重插值 + 行列式"如果能推广，下一批目标会是 log 2、ζ(3)、其他对数值的无理性指数（推理摘要第 43 节提到模型"considered an extension to algebraic logarithms"，但这是推测性方向，没有结论 ⚠）。

### 9.2 对数学：不意味着什么

| 常被混淆的说法 | 和 μ(π) = 2 的关系 |
|---|---|
| π 是无理数 | 早已知道（Lambert 1761）。μ = 2 远强于"无理" |
| π 是超越数 | 早已知道（Lindemann 1882）。而且超越数可以有 μ = ∞（Liouville 数），两者互不推出 |
| π 的连分数部分商有界 | **仍未解决**。论文明确说 μ = 2 不等于这一点 |
| π 是正规数（每种数字串出现频率相同） | **仍未解决**，是完全不同的问题 |
| 能算出"从哪个分母开始不再有超常逼近" | **不能**，Q(ν) 不可有效计算 |
| 22/7、355/113 这样的好逼近不存在 | 当然存在。μ = 2 只说"指数 > 2 的奇迹"只有有限多个 |

### 9.3 对计算机科学

几乎没有直接影响。

- 浮点数的三角函数要做"参数约减"（把大数 x 减到 [−π/4, π/4] 区间），最坏情况取决于某个浮点数离 π/2 的倍数有多近。但这是**有限范围**的问题（double 的范围是有限的），工程上早已用连分数把最坏情况直接算出来（见 J.-M. Muller, *Elementary Functions*, 参数约减一章 ⚠ 具体章节以原书为准）。一个"渐近的、不给门槛的"定理不会改变这些具体数字。
- 和密码学、复杂度理论没有关系。

### 9.4 对 AI

1. 这是 "AI 解决一个被文献正式记录的经典猜想" 的一个相对**容易检验**的案例：陈述短、只用标准定义、Lean 证明不依赖补丁库。如果你想向别人说明"这批结果里哪些最可信"，它比准黎曼猜想更好举例。
2. 推理摘要展示了一个值得研究的过程特征：保守目标（2.5）+ 长时间失败探索（40 多节）+ 大量自我审计，最后发现技术的真正上限。对研究 AI 的研究过程本身（以及 eval 设计）有参考价值。
3. 生态层面：同月有 Bai 的 7.1018 预印本（本 deck 作者的研究笔记记录：Bai 在致谢中提到 OpenAI 模型协助 ⚠ 未复核原文）、被撤回的 Flint Hills 声明、formal-conjectures 上 AI 起草的 issue。"AI 协助的数学声明"数量在激增，人类专家的审读带宽仍是瓶颈，和第 1 章的结论一致。

## 附：【检查】答案

- **检查 1**：355/113 = 3.14159292…，与 π 差约 2.67×10⁻⁷；113² = 12769；乘积约 0.0034，即比 1/q² 好了约 290 倍。
- **检查 2**：355 = 3 × 113 + 16，所以 355/113 = 3 + 16/113 = 3 + 1/(113/16)；113 = 7 × 16 + 1，所以 113/16 = 7 + 1/16。合起来 355/113 = [3; 7, 16]。（π 本身是 [3; 7, 15, 1, …]，而 [3; 7, 15, 1] = [3; 7, 16]，两种写法是同一个分数。）
- **检查 3**：q = 2（0.283）和 q = 9（0.274）都在 [0.2, 0.3) 里，差是 7，又得到 22/7。（q = 3 和 q = 10 都在 [0.4, 0.5)，差也是 7。Q = 10 时抽屉原理只能"看到"分母 ≤ 10 的分数，最好的就是 22/7。）
- **检查 4**：sin(355) = sin(355 − 113π) ≈ 3.01×10⁻⁵（脚本实算 355 − 113π = 3.0144×10⁻⁵）。sin² ≈ 9.09×10⁻¹⁰；355³ ≈ 4.47×10⁷；乘积 ≈ 0.0407，倒数 ≈ 24.6。

## 附：术语表

| 术语 | 一句话解释 |
|---|---|
| 有效指数 ν | 若 \|x − p/q\| ≈ q^(−ν)，这个逼近的"超常程度"就是 ν |
| 连分数 | 反复"取整、取倒数"得到的展开 [a₀; a₁, a₂, …] |
| 渐近分数 | 连分数截断得到的分数，是同等分母下的最佳逼近 |
| 部分商 | 连分数里的各个 aᵢ；越大说明它前一个渐近分数越准 |
| Dirichlet 逼近定理 | 每个无理数都有无穷多个 \|x − p/q\| < 1/q² 的逼近 |
| 无理性指数 μ(x) | 能被"无穷多次"以 q^(−ν) 精度逼近的最大 ν |
| 代数数 | 某个整系数多项式的根，如 √2、∛2 |
| 超越数 | 不是代数数的数，如 π、e、Liouville 数 |
| Roth 定理 | 所有代数无理数 μ = 2（1955，Fields 奖） |
| Liouville 数 | μ = ∞ 的数，例如 Σ 10^(−k!) |
| 线性形式 aπ − b | 旧方法构造的"很小但非零"的量，用来给 μ 定上界 |
| 不可有效（ineffective） | 证明了某个常数存在，但无法算出它的值 |
| Flint Hills 级数 | Σ 1/(n³ sin²n)，收敛性由 μ(π) 决定 |
| 部分商有界（badly approximable） | \|x − p/q\| ≥ c/q² 对所有分数成立；比 μ = 2 更强 |
| 正规数 | 每种数字串在展开中出现频率都相同的数；与 μ 无关 |
