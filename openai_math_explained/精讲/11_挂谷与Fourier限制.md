## 14.1 一根针怎么转身：挂谷的问题（1917）

### 14.1.1 问题与三个候选形状

平面上有一根长为 1 的针。要让它**连续地**移动并掉头 180°（两端互换），扫过的区域面积最少是多少？问题来自 Fujiwara 和挂谷宗一（Sōichi Kakeya）1917 年的文章（OpenAI 两篇论文都引用了它 [P]）。

| 区域 | 针怎么转 | 面积（脚本实算） |
|---|---|---|
| 直径为 1 的圆盘 | 绕圆心原地转 | π/4 ≈ 0.7854 |
| 高为 1 的正三角形 | 贴着三条边轮流转 | 1/√3 ≈ 0.5774 |
| 挂谷的三尖瓣线（deltoid） | 针始终和曲线相切 | π/8 ≈ 0.3927 |

- 正三角形：Pál（1921 年前后）证明它在**凸**区域里最小 [R]。
- 三尖瓣线：半径 r 的小圆在半径 3r 的大圆里滚动，小圆上一点画出的曲线。任一条切线被它截出的线段长都是 4r，取 r = 1/4 就是 1。脚本在三个切点上验证切线段长都是 **1.000000**，鞋带公式算出面积 **0.392699** = π/8。挂谷似乎猜它最小 [R]。

【检查 1】高为 1 的正三角形，边长和面积各是多少？（提示：高 = 边长 × √3/2。）

### 14.1.2 Besicovitch：面积可以任意小

答案出人意料：**没有正的最小值。** Besicovitch 1928 年证明针可以在面积任意小的区域里掉头 [P，据 OpenAI 两篇论文的引言]。他更早还构造出一个**面积为零**、却在每个方向都含有单位线段的集合（Wikipedia 记为 1920 年 [R]；⚠ 年份以原文为准）。

两个直觉：
1. **Perron 树**。顶角 60° 的三角形含有 60° 范围内所有方向的线段。把底边切成 2ᵏ 份得到 2ᵏ 个细三角形，再左右平移让它们大面积重叠，每块仍保留自己那段方向。总面积可以压到任意小；三份转 60° 拼起来覆盖全部方向 [R]。
2. **沿着自己走不花面积**。要把针横向挪一点，可以先沿自身走很远，转一个极小的角再走回来，只扫过两个细长三角形。

OpenAI 三维论文特意提醒："能连续掉头"和"每个方向都有一根针"是两回事（"These are different requirements."）[P]。后者不要求针能动。

**定义**：ℝⁿ 中对每个方向都包含一根该方向单位线段的集合，叫**挂谷集**（也叫 Besicovitch 集）。它的面积（体积）可以是 0。那还问什么？问的是：**面积为零的集合也有大小之分。** 一条线段和一个康托集面积都是零，前者显然"更大"。下一节的"维数"就是量这种大小的尺子。

## 14.2 维数：怎么量一个"面积为零"的集合有多大

### 14.2.1 数格子（盒维数）

用边长为 δ 的小方格盖一个集合，至少要 N(δ) 个。线段要 δ⁻¹ 个，正方形要 δ⁻² 个。规律是 N(δ) ≈ δ^(−d)，指数 d 就是维数：

```
d ≈ log N(δ) / log(1/δ)      （δ 越小越准）
```

这叫**盒维数**（box-counting dimension，也叫 Minkowski 维数）。脚本实数：线段在 δ = 0.1、0.01、0.001 时 N = 10、100、1000，估计值 1.0000；正方形同样算得 2.0000。

### 14.2.2 康托集：维数可以不是整数

从 [0, 1] 开始，去掉中间 1/3，每段再去掉中间 1/3，无限重复。剩下的**康托集**总长度为 0（每步保留 2/3），但有不可数多个点。用 δ = 3⁻ᵏ 的格子盖，第 k 步剩 2ᵏ 段，N = 2ᵏ。脚本用第 12 层近似：δ = 3⁻²、3⁻⁴、…、3⁻¹⁰ 时 N = 4、16、64、256、1024，估计值全是 **0.6309**。

【检查 2】用 N(3⁻ᵏ) = 2ᵏ 证明康托集的盒维数恰好是 log 2 / log 3。

### 14.2.3 Hausdorff 维数：允许大小不同的格子

盒维数要求所有格子**一样大**，这会出毛病。看可数集合 {1, 1/2, 1/3, 1/4, …}：直觉上它是 0 维。但脚本数格子：δ = 10⁻²、10⁻³、10⁻⁴、10⁻⁵ 时 N = 20、63、200、632，正好等于 2/√δ，盒维数是 **1/2**。原因是点在 0 附近越挤越密，等大格子看不出它们其实是孤立点。

**Hausdorff 维数**允许用**大小不同**的集合去盖，第 i 块直径记 rᵢ，看"s 维代价" Σ rᵢˢ 能否压到任意小，能压到 0 的最小 s 就是 Hausdorff 维数。OpenAI 四维论文用的就是这个覆盖定义，并强调它不需要集合可测 [P]。

【检查 3】给 {1/n} 的第 k 个点一个长度为 ε·2⁻ᵏ 的区间。证明 Σ (ε·2⁻ᵏ)ˢ 对任何 s > 0 都随 ε → 0 趋于 0。

一般有 **Hausdorff 维数 ≤ 下盒维数 ≤ 上盒维数**。所以"Hausdorff 维数 = n"是最强的说法，自动推出盒维数也是 n（四维论文 §11.1 正是这样推的 [P]）。

## 14.3 挂谷猜想：面积可以是零，维数却不能少

### 14.3.1 陈述与管子版本

> **挂谷集合猜想**：ℝⁿ 中的每一个挂谷集，Hausdorff 维数（因而盒维数）都等于 n。

白话：针可以挤得让总体积为零，但不能挤得让集合"薄"一个维度。

实际处理的是有限版本：把每根针加粗成半径 δ、长 1 的**δ-管**。在 ℝ³ 里，方向两两相差至少 δ 的管子约有 δ⁻² 根，每根体积 πδ²，互不重叠时总体积 ≈ π（脚本实算：δ 从 0.1 到 0.0001 都是 3.1416）。问题变成：**这么多不同方向的细管子最多能重叠到什么程度？** 盒维数版的猜想大致等价于：并集体积 ≥ c_ε·δ^ε，对每个 ε > 0。重叠最多只能"省下 δ 的任意小幂次"。

平面上能看清"面积为零"和"维数满"怎么共存。Córdoba 1977 年的平面极大估计 [P，被引用] 推出：平面上这种管子并集面积至少约 1/log(1/δ)，Besicovitch 型构造说明这大致能取到（⚠ 锐利性细节我没核对原文）。脚本实数：δ = 10⁻²、10⁻⁶、10⁻¹²、10⁻¹⁰⁰ 时 1/ln(1/δ) = 0.2171、0.0724、0.0362、0.0043。面积确实趋于 0，但比任何 δ^ε 都慢，所以维数仍是 2。**"面积为零"是对数级的节省，"维数不满"需要幂次级的节省。**

## 14.4 有限域上的挂谷问题：一个可以手算的版本

### 14.4.1 F₃ 平面与最小挂谷集

**有限域 F_q**（q 是素数）就是模 q 的整数 {0, 1, …, q−1}。F₃ 里 2 + 2 = 1，2 × 2 = 1。**F_q 平面**有 q² 个点；一条直线 {a + t·v : t ∈ F_q} 恰有 q 个点；方向共 q + 1 个（斜率 0…q−1 加竖直）。**有限域挂谷集**是在每个方向上都含一整条直线的点集。Wolff 1999 年把它提为实数问题的玩具模型 [R]。

平面上有个初等下界：不同方向的两条线恰交于一点，所以第一条贡献 q 个点，第二条至少新增 q−1 个……总数 ≥ q + (q−1) + … + 1 = q(q+1)/2。

脚本穷举了"每个方向选一条线"的全部组合（用平移把竖直线固定为 x = 0）：

| q | 平面点数 | 搜索组合数 | 最小挂谷集 | 初等下界 | Blokhuis–Mazzocca 公式 | 占比 |
|---|---|---|---|---|---|---|
| 3 | 9 | 27 | **7** | 6 | 7 | 0.778 |
| 5 | 25 | 3,125 | **17** | 15 | 17 | 0.680 |
| 7 | 49 | 823,543 | **31** | 28 | 31 | 0.633 |

穷举和 Blokhuis–Mazzocca 2008 年的精确公式 q(q+1)/2 + (q−1)/2（q 为奇数）完全吻合 [R，arXiv:0911.4370，没读原文，但三个 q 都穷举验证了]。q = 3 的一个最小挂谷集（脚本输出）：

```
点：(0,0) (0,1) (0,2) (1,0) (1,1) (2,0) (2,2)
线：x = 0；y = 0；y = x；y = 2x + 1
```

【检查 4】手工验证四条线各自的 3 个点都在这 7 个点里（y = 2x + 1 在 x = 0, 1, 2 时 y = 1, 0, 2，模 3）。

占比在下降，趋向 1/2，但**不趋向 0**。这就是有限域版的"维数满"：挂谷集的大小和整个空间 qⁿ 同一量级。

### 14.4.2 Dvir 的多项式方法（2008）

Dvir 2008 年用一个很短的论证证明 F_qⁿ 中的挂谷集至少有 C_n·qⁿ 个点，此前最好的一般下界约为 q^(4n/7) [P，arXiv:0803.2336 摘要]。在 q = 3、n = 2 上完整走一遍：

**第 1 步：点少，就有多项式在上面全为零。** 次数 ≤ 2 的二元单项式有 6 个：1, y, y², x, xy, x²。要求多项式在 K 的每点取 0，是关于 6 个系数的 |K| 个线性方程。|K| ≤ 5 时未知数多于方程，必有非零解。脚本核对：F₃² 的全部 126 个 5 点子集，**每一个**都有这样的非零多项式。

**第 2 步：在整条线上为零，会泄露"最高次部分"。** 把 P 限制到线 a + t·v 上，得到 t 的一元多项式，次数 ≤ 2，却在 t = 0, 1, 2 都为 0，所以恒为零。它的 t² 系数恰好是 P 的最高次齐次部分在 v 处的值。结论：**K 在方向 v 上有整条线 ⟹ P 的最高次部分在 v 处为 0。**

**第 3 步：矛盾。** 若 K 是挂谷集，最高次部分在所有方向上为 0，于是在 F₃² 全部 9 个点上为 0。但脚本检查了全部 728 个次数 ≤ 2 的非零多项式，在 9 个点上全为零的有 **0** 个。所以挂谷集至少 6 个点。

一般情形一样：次数 ≤ q−1 的 n 元单项式有 C(q+n−1, n) 个，所以 |K| ≥ C(q+n−1, n) ≥ qⁿ/n!。

例子（脚本输出）：S = {(0,0), (0,1), (0,2), (1,0), (2,0)}，是 x = 0 和 y = 0 拼成的"十字"。P = xy 在上面全为零，它的最高次部分只在方向 (1,0)、(0,1) 上为零，所以 S 最多只在这两个方向上含整条线，事实正是如此。

【检查 5】验证 xy 在十字的 5 个点上都为 0，在方向 (1,1)、(1,2) 上不为 0。

### 14.4.3 为什么实数难，以及一条从 CS 到分析的迁移路线

在 F_q 里，线只有 q 个点，"次数 < q 的多项式在线上全为零就恒为零"直接可用。在 ℝⁿ 里有**无穷多个尺度**：管子可以在粗尺度散开、细尺度挤在一起，或者反过来。实数问题的难度几乎都在多尺度上，Wang–Zahl 和 OpenAI 的论文都花大量篇幅处理它 [P]。实数上还有"代数障碍"：管子可能聚在低次代数曲面附近，Guth–Zahl 的多项式 Wolff 公理就是为排除它 [P，被引用]。

Dvir 是理论计算机科学家，他的论证和编码理论的多项式插值（Reed–Muller 码、Sudan 的列表解码）同源 [已确立]。Guth 随后把它搬进实数世界：2010 年多线性挂谷端点情形 [P，被引用]、Guth–Katz 2015 年 Erdős 不同距离问题 [R]、2016 年用"多项式分割"把三维限制推到 p > 13/4 [P，被引用]。**一个 CS 计数技巧，十几年后成了调和分析的主力工具。**

## 14.5 挂谷极大猜想：只亮了一部分的管子

### 14.5.1 极大函数

给 ℝ³ 上一个函数 f（想成一团"密度"）。对每个方向 ω，在空间所有位置里找一根方向为 ω、长 1、半径 δ 的管子，使 |f| 在管子里的平均值最大：

```
K_δ f(ω) = 在所有位置 a 上取最大值 [ (1/(πδ²)) × ∫ 在管子 T_δ(a, ω) 里 |f(x)| dx ]
```

这是 OpenAI 三维论文开头的定义 [P]。K_δ f 是球面上的函数，每个方向一个数。

> **挂谷极大猜想（三维）**：对每个 ε > 0 存在 C_ε，使对所有 0 < δ < 1 和所有 f：‖K_δ f‖_{L³(S²)} ≤ C_ε · δ^(−ε) · ‖f‖_{L³(ℝ³)}。

这里 ‖g‖_{L³} = (∫|g|³)^(1/3)。

### 14.5.2 平凡界 δ^(−2/3)

用 Hölder 不等式，单根管子里的平均值 ≤ (πδ²)^(−1/3)·‖f‖₃，再对球面积分：

```
‖K_δ f‖₃ ≤ (4π)^(1/3) · (πδ²)^(−1/3) · ‖f‖₃      （像 δ^(−2/3) 那样变大）
```

这正是 OpenAI 仓库 Lean 文件里**唯一**关于极大函数的实质定理（`maximal_norm_le_holder`，§14.8.1）[P]。和猜想形状（取 ε = 0.01）比较，脚本实数：

| δ | 平凡界的常数 | 猜想形状 δ^(−0.01) |
|---|---|---|
| 10⁻² | 34.2 | 1.047 |
| 10⁻⁴ | 736.8 | 1.096 |
| 10⁻⁶ | 15,874.0 | 1.148 |

### 14.5.3 λ 和 λ³：为什么极大版本更强

**极大 ⟹ 集合**。取 f 为一堆管子并集的指示函数。每个方向都有一根管子完全在并集里，平均值为 1，所以左边 ≈ (4π)^(1/3)，右边 ‖f‖₃ = (并集体积)^(1/3)。代入得并集体积 ≳ δ^(3ε)，就是集合猜想的离散版。

**只让每根管子亮一部分。** 每根管子 T 只有子集 Y(T) 被点亮，|Y(T)| ≥ λ·|T|，0 < λ ≤ 1。取 f 为亮段并集的指示函数，同样计算：

```
（每个方向的平均值 ≥ λ）  ⟹  (4π)^(1/3) · λ ≤ C δ^(−ε) · |亮段并集|^(1/3)
                         ⟹  |亮段并集| ≳ δ^(3ε) · λ³
```

这正是三维论文的不等式 (1.1)：|∪Y(T)| ≳ δ^ε · λ³ · Σ|T| [P]。λ³ 的"3"来自 L³ 范数。

【检查 6】若极大不等式的常数是 C·δ^(−ε)，每根管子恰好亮一半（λ = 1/2），亮段并集体积至少多少？

**为什么 λ 的幂次是关键**。论文原话：Wang 和 Zahl 的集合定理给出的是 λ^(K(ε)) 形式，"the need to replace it by λ³ is stated explicitly after their theorem" [P]。用一个**编造的** K = 100 对比量级（⚠ 不是真实指数，脚本实算）：λ = 0.5 时 λ³ = 0.125，λ¹⁰⁰ = 7.89×10⁻³¹。应用里 f 要按取值大小分层，每层都是"亮了 λ 那么一段"的管子，λ 取遍 1/2, 1/4, 1/8, …；λ¹⁰⁰ 式的依赖在分层求和时会爆掉，λ³ 恰好和 L³ 匹配。**集合猜想对 λ 的依赖差一点也能推出（论文："A set-dimension conclusion can follow from weaker dependence on λ"），极大猜想要求最优的 λ³，所以严格更强**；§14.6 的应用需要的都是极大版本。

**对偶版本**：**Nikodym 集**要求一大片点上每点都有一根穿过它、几乎整根在集合里的线段。三维论文 §11 用 Gao–Liu–Xi 的转移定理从极大定理推出了 Nikodym 极大估计 [P]。

## 14.6 分析学家为什么关心：波、Fourier 限制和 Bochner–Riesz

### 14.6.1 只用一种波长的波：球面延拓

ℝ³ 里的"正弦波"是平面波 e^(2πi x·ξ)：波峰是垂直于 ξ 的一族平行平面，波长 1/|ξ|。任何函数都是平面波的叠加。现在只允许 |ξ| = 1，即**波长都是 1、方向任意**的波，每个方向 ω 给一个复数权重 g(ω)：

```
Eg(x) = ∫ 在单位球面 S² 上 g(ω) · e^(2πi x·ω) dσ(ω)
```

这是 077 号论文的**延拓算子** [P]，物理上是"同一频率、从各方向射来的单色波"叠加出的场。名字来历：Stein 原来问 Fourier 变换能否有意义地**限制**到球面这个体积为零的集合上，球面的**曲率**让这在一定范围内可能；延拓是它的对偶 [已确立]。

### 14.6.2 最简单的例子与 p > 3 的门槛

取 g ≡ 1，可以直接积出（论文给出 [P]）：E1(x) = 2 sin(2π|x|) / |x|。脚本数值积分核对：|x| = 0.25、1.3、5.7 时得 8.000000、1.463164、−0.333704，和公式一致。

它像 1/|x| 那样衰减。∫|E1|ᵖ 在 ℝ³ 上大约是 ∫ r^(−p)·r² dr，**p > 3 时有限，p ≤ 3 时发散**。脚本实数（∫ 在 1 < |x| < R 上）：

| p | R = 10 | R = 100 | R = 1000 |
|---|---|---|---|
| 3 | 97.95 | 196.19 | 294.43 |
| 3.5 | 76.66 | 101.09 | 108.82 |
| 4 | 66.75 | 73.53 | 74.21 |

p = 3 时 R 每乘 10 多出约 98，对数发散；p = 3.5、4 收敛。

> **Stein 限制猜想（三维、有界数据）**：对每个 p > 3 存在 C_p，使所有有界的 g 满足 ‖Eg‖_{Lᵖ(ℝ³)} ≤ C_p · sup|g|。

即"所有波在原点汇聚"已是最坏情况。n 维的门槛是 p > 2n/(n−1)，二维（p > 4）在 1970 年代已解决（Fefferman、Zygmund）[R]。三维进展：

| 谁 | p 的门槛 | 来源 |
|---|---|---|
| Tomas–Stein（L² → L⁴） | 4 | [P] |
| Tao 2003，双线性 | 10/3 ≈ 3.3333 | [R] ⚠ 未重读原文 |
| Bourgain–Guth 2011，多线性 | 3.3 | [R] ⚠ 未重读原文 |
| Guth 2016，多项式分割 | 13/4 = 3.25 | [P] |
| 王虹 2018 起，"扫帚"方法（抛物面） | 42/13 ≈ 3.2308 | [P] |
| Wang–Wu 2024，两端 Furstenberg + 精细解耦 | 22/7 ≈ 3.1429 | [P] |
| **OpenAI 声称** | **3（全部开放范围）** | [P] |

（[P] 的门槛都直接出现在 077 号论文引言里。）

### 14.6.3 为什么限制猜想管得住挂谷：波包就是细管子

全章最关键的一步：
1. **测不准原理**。把球面切成直径约 δ 的小帽子。只用一顶帽子里的方向，叠加出的波集中在一根宽约 1/δ、长约 1/δ² 的管子上，方向垂直于帽子。这叫**波包** [已确立]。你在 EEG 时频分析里见过同一件事：频率上越窄，时间上越宽。（V1 简单细胞常用 Gabor 函数建模，Daugman 1985，也是空间和频率同时局部化的"波包"；这只是类比。）
2. **每顶帽子一根管子**。坐标缩小 δ² 倍后，它们变成长 1、宽 δ、方向两两相差约 δ 的管子，正是§14.3.1 的挂谷构型。
3. **重叠 ⟹ Lᵖ 范数变大**。给每个波包一个随机正负号，|Eg|² 大致等于"经过该点的管子数"。管子若按 Besicovitch 方式高度重叠，能量就挤在很小的集合上，p > 2 时 Lᵖ 范数变大。限制估计禁止这事。**限制猜想 ⟹ 挂谷猜想** [已确立，Bourgain 1991 起]。

反过来不成立：挂谷只数管子重叠，相当于"扔掉相位的限制问题"；限制还要处理波之间的干涉，所以更难。

### 14.6.4 理想低通滤波器的意外：Fefferman 1971 和 Bochner–Riesz

工程上最自然的滤波是"理想低通"：频率空间里 |ξ| ≤ 1 的保留，其余砍掉。一维时这在每个 Lᵖ（1 < p < ∞）上有界 [已确立]。**Fefferman 1971 年证明：二维及以上，球形截断只在 p = 2 时有界**，反例正是用 Besicovitch 集造的（078 号论文引言："Using a Kakeya construction, Fefferman proved…" [P]）。

补救办法是把截断边缘磨圆：乘以 (1 − |ξ|²)^δ（|ξ| < 1 时），叫 **Bochner–Riesz 平均**。这里的 δ 是磨圆程度，和管子半径无关，是历史记号。

> **Bochner–Riesz 猜想**：δ > max( n·|1/p − 1/2| − 1/2, 0 ) 就在 Lᵖ 上有界 [P，078 号论文]。

脚本算的三维门槛：p = 1 或 ∞ 时 1.0；p = 6 时 0.5；p = 4 时 0.25；**3/2 ≤ p ≤ 3 时是 0**，任何一点磨圆都够。二维已由 Carleson–Sjölin 解决；三维此前到 max{p, p′} ≥ 22/7（Gao–Wu–Xi）[P，078 号论文引言]。

【检查 7】n = 3、p = 4 时，门槛 3·|1/4 − 1/2| − 1/2 是多少？

### 14.6.5 一条蕴含链

在三维，这几个猜想排成一条链（每个箭头都在 OpenAI 相应论文的引言里被引用 [P]）：

```
局部光滑（波动方程）⟹ Bochner–Riesz ⟹ Fourier 限制 ⟹ 挂谷极大 ⟹ 挂谷集合
      Sogge             Tao 1999       §14.6.3            §14.5.3
```

**局部光滑**：三维波动方程的解在固定时刻会损失一部分光滑性，但在一段时间上平均后能挽回几乎全部。这是 Sogge 1991 年的猜想 [R]；二维由 Guth–Wang–Zhang 解决 [P，被引用]。

OpenAI 声称在两天里把这条链在三维**从头到尾**打通（§14.7.2）；此前只有最后一环被王虹和 Zahl 拿下。

### 14.7.3 三维极大论文的思路（只读了引言，简化版）

按论文 §1.2 转述，细节远多于此 [P]：
1. **反证**：定义"临界指数"，即不等式对所有构型成立还至少要多乘多少 N 的幂次（N = 1/δ）。若它 > 0，就有一列"几乎取到等号"的极端构型（类比组合里的最小反例）。
2. **极端构型被迫长成特定形状**：多线性挂谷（Bennett–Carbery–Tao，Guth 端点版）推出短时间段上方向几乎共面；Ren–Wang 平面 Furstenberg 定理推出"板"里密度足够。这正是 Katz–Łaba–Tao 说的平面性和颗粒性。一个"最小延迟"论证再迫使时间剖面成为标准形 F(s) = β(s − τ)₊，论文称为"平稳"。
3. **信息论记账**：每根管子用位置 X, Y 和速度 U, V 四个坐标描述，用**条件熵**（按 log N 归一化，可理解为对数尺度的格子数）度量各坐标携带的信息。同一根线上的两个事件给出两个"参考系"，差一个 2×2 矩阵；平面投影定理约束熵增长率（"钉扎"一步改编自 Shmerkin–Wang、Orponen–Shmerkin–Wang）。
4. **矛盾**：约束若不成立，真实联合分布和独立乘积分布之间要有正量互信息，而平均估计显示可用的更少。所以临界指数是 0，再把估计推广到任意 L³ 函数，全程保住 λ³。

对 CS 读者：像用"信息量"做势函数的下界证明（我的类比）。

### 14.7.4 四维论文的思路（同样只读了引言）

1. **反证**：假设有 Hausdorff 维数 < 4 的挂谷集，把它变成"加权直线问题"：用"图表"（chart：一组线段片段加一个时间区间，上面某个**二次多项式检验**保持很小）去拟合直线。反例意味着拟合要付出正的"时间代价"（horizon H(E) > 0）[P]。二次多项式对应§14.4.3 说的代数障碍。

### 14.8.3 多条路线互相印证，但不独立

这一簇有个罕见结构：几个结论有**两条独立声称的证明路线** [P]：

|---|---|---|
| 三维挂谷极大 | 074 直接证明 | 077 球面限制 ⟹ 推论 1.3 |
| 球面限制 p > 3 | 077 直接证明 | 078 Bochner–Riesz ⟹ Tao 1999 |
| 三维 Bochner–Riesz | 078 直接证明 | 079 局部光滑 ⟹ 推论 11.2 |

## 14.9 如果为真，意味着什么（以及不意味着什么）

### 14.9.1 对数学

1. **四维挂谷：从 3.059 直接到 4**，此前约 30 年只推进了缺口的 5.9%。附带 [P]：盒维数也是 4；ℝᵈ（d ≥ 4）中挂谷集维数都 ≥ 4；常曲率四维流形上 Nikodym 集维数是 4（Gao–Liu–Xi 猜想 1.4 的四维情形）；方向集维数公式（Keleti–Máthé：含 D 中每个方向线段的集合维数 ≥ 1 + dim D）。
2. **三维挂谷极大**：λ³ 的最优依赖，给出 ℝ³ 和常曲率三维流形上的 Nikodym 极大估计、一类弯曲挂谷极大估计 [P]，并是 077 正曲率曲面限制定理的输入。
3. **如果整簇为真**：三维的局部光滑 ⟹ Bochner–Riesz ⟹ 限制 ⟹ 挂谷整条链在严格范围内全部成立。这些是调和分析过去 50 年的中心问题，在三维一起关掉，分量相当于一整代研究计划（推测）。
4. **没关掉的**：五维及以上的挂谷集合猜想；四维及以上的极大、限制、Bochner–Riesz、局部光滑；三维的端点情形（论文都明说不处理端点）[P]。

### 14.9.2 对 CS

- **实数挂谷对 CS 没有直接影响**（推测）。CS 用的是有限域版本，Dvir 2008 年已解决。
- 有限域版本用于**随机性提取**（把"有偏"的随机源变成近似均匀的比特）。Dvir–Wigderson 2008（*Kakeya sets, new mergers and old extractors*）用挂谷型界分析"合并器"：几个随机变量里有一个均匀但不知是哪个，输出它们所在直线上的一个点，挂谷界保证输出仍有很高的熵 [R]。Dvir–Kopparty–Saraf–Sudan 2009 把下界改进到 qⁿ/2ⁿ，据此造出种子长度为对数的提取器 [P，arXiv:0901.2529 摘要]。
- 反方向见§14.4.3：多项式方法从 CS 进入了实数分析。

### 14.9.3 对 AI

- **速度**：Wang–Zahl 预印本（2025-02-24）到 OpenAI 四维手稿（2026-09-24）**19.0 个月**；Guth–Wang–Zahl 精简版（2026-01-20）到四维手稿 **8.1 个月**；菲尔兹奖到 OpenAI 公开发布 **75 天**（脚本实算）。
- **"被抢先"**：Quanta 把四维称为王虹和同行们"显而易见的下一个目标"[R]；王虹–Zakharov 的粘性管族论文比四维手稿早六天 [P]；Alpöge 点名"挂谷极大"的抢先和利益冲突 [R] ⚠。一份没人审过、没有 Lean 证明的 175 页手稿，可能已经改变了一批博士生和博士后的选题：若有错，领域要花人力找错；若对，研究计划要改写。这就是§23.9"AI 产出知识的政治经济学"的具体样子：控制权在"何时发、发什么、附不附证明"。能读懂这些论文的基本就是被引用的那几十位作者和学生，**验证成本由被抢先的社区承担**（推测）。
- **方法观察**：这一簇共享"极端构型 + 熵记账 + Ren–Wang"的发动机。可能是模型找到了可复用的引擎，也可能意味着错误相关（§14.8.3）（推测）。

### 14.9.4 不意味着什么

- **不意味着王虹的工作被超越或贬值**：这些证明建立在她的工具上，三维集合猜想是她和 Zahl 证明的。
- **不意味着已经证明**：截至 2026-10-09 没有 Lean 证明，没有公开审读；高维问题也还开放（§14.9.1 第 4 条）。

## 附：【检查】答案

- **检查 1**：边长 = 2/√3 ≈ 1.1547；面积 = ½ × 边长 × 高 = 1/√3 ≈ 0.5774（脚本核对）。
- **检查 2**：log 2ᵏ / log 3ᵏ = k·log 2 / (k·log 3) = log 2 / log 3 ≈ 0.6309，和 k 无关。
- **检查 3**：Σₖ (ε·2⁻ᵏ)ˢ = εˢ · Σₖ 2^(−ks) = εˢ / (2ˢ − 1)。s > 0 时分母是正常数，ε → 0 时整体 → 0，所以 Hausdorff 维数是 0。
- **检查 4**：x = 0 → (0,0), (0,1), (0,2)；y = 0 → (0,0), (1,0), (2,0)；y = x → (0,0), (1,1), (2,2)；y = 2x + 1 → (0,1), (1,0), (2,2)。全在 7 个点里，四条线的方向正好是竖直和斜率 0、1、2。
- **检查 5**：十字上每点要么 x = 0、要么 y = 0，所以 xy = 0。方向 (1,1)：1·1 = 1 ≠ 0；方向 (1,2)：1·2 = 2 ≠ 0。
- **检查 6**：(4π)^(1/3)·λ ≤ C δ^(−ε)·V^(1/3)，所以 V ≥ 4π·λ³·δ^(3ε)/C³ = (π/2)·δ^(3ε)/C³。
- **检查 7**：3 × 0.25 − 0.5 = 0.25（脚本核对）。
