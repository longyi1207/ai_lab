## 7.0 先说结论：这一章要讲明白的一件事

很多重要的优化问题（把网络切成两半、选最少的哨兵看住所有路……）被认为**没有快速的精确算法**。退而求其次，我们问：**快速算法最多能保证做到最优解的百分之几？**

对其中最经典的 Max-Cut 问题，1995 年有人给出一个能保证 **87.8%** 的算法。另一边，1997–2001 年有人证明保证 **94.1%** 以上是 NP 难的。中间这 6 个百分点，30 年没人知道真相在哪里。

这一章要讲清楚的是一条因果链：

> 近似能做到多好 ⟸ 由"区分几乎能满足和远远不能满足"有多难决定 ⟸ 最关键的一种约束系统叫 Unique Games ⟸ 唯一博弈猜想（UGC）说：这种区分是 NP 难的。

**如果 UGC 成立**，那么 87.8% 就**恰好**是 Max-Cut 的极限，而且同一个论证能一次性确定一大类问题的近似极限。Khot 在 2002 年提出它，24 年来没人能证明或推翻。**OpenAI 声称证明了它**，并附上了 Lean 形式化证明。

读完这一章，你应该能用自己的话讲出：
- 为什么"完全能满足"的 unique game 很容易，而"几乎能满足"的被猜想是难的；
- UGC 和 0.878 这个数之间具体是什么关系；
- OpenAI 的结果如果为真，意味着什么，以及它**不**意味着什么（它和 P vs NP 无关）。

## 7.1 P vs NP 与 NP 难：5 分钟版

### 7.1.1 "容易验证"不等于"容易找到"

数独：给你一个填好的盘面，检查对不对只需要几秒；从空盘面开始填，却可能要试很久。

- **P**：能在多项式时间（比如 n²、n³ 步）**找到**答案的问题。
- **NP**：给你一个候选答案，能在多项式时间**验证**它对不对的问题。

**P vs NP** 问的是：凡是容易验证的，是否都容易找到？几乎所有人相信 **P ≠ NP**，但没人证明（Clay 千禧年难题之一）。

### 7.1.2 归约与 NP 难

**归约**：把问题 A 的任何实例，快速地翻译成问题 B 的实例，使得 B 的答案就是 A 的答案。如果能这样做，"B 有快速算法"就推出"A 有快速算法"，所以 B 至少和 A 一样难。

**3SAT**：给一堆形如 "(x₁ 或 非x₂ 或 x₅)" 的条款，每个条款 3 个变量，问能不能给变量赋真/假，使所有条款同时成立。Cook–Levin 定理（1971）说：NP 里的每个问题都能归约到 3SAT。

**NP 难**：如果 3SAT 能归约到问题 B，就说 B 是 NP 难的。意思是：**除非 P = NP，否则 B 没有多项式时间算法。**

> 这一章所有"X 是 NP 难的"都要读成"除非 P = NP，否则 X 做不到"。它们都**不**证明 P ≠ NP，只是把 X 的命运和 P vs NP 绑在一起。

## 7.2 退而求其次：近似算法

### 7.2.1 Max-Cut

给一张图，把顶点分成两组（比如涂成黑和白），一条边如果两端颜色不同就算"被切"。**Max-Cut** 问：最多能切多少条边？判断"能否切到 ≥ k 条"是 Karp 1972 年列出的 21 个 NP 完全问题之一。

脚本实算（暴力枚举所有涂色）：

| 图 | 边数 | 最大切 | 随机涂色期望切 | 随机 / 最优 |
|---|---|---|---|---|
| 三角形 | 3 | 2 | 1.5 | 0.750 |
| 5-环（五边形） | 5 | 4 | 2.5 | 0.625 |
| Petersen 图 | 15 | 12 | 7.5 | 0.625 |

三角形为什么最多切 2 条：三个点只有两种颜色，必有两个点同色，它们之间那条边切不到。

### 7.2.2 近似比和"随便做就有 1/2"

一个**α-近似算法**：多项式时间内，总能给出至少"α × 最优值"的解。

**随机涂色**：每个点独立地抛硬币决定颜色。一条边两端颜色不同的概率是 1/2，所以期望切到"边数的一半"。因为最优值不可能超过边数，随机涂色至少是 **1/2-近似**。

1/2 这个数从 1976 年（Sahni–Gonzalez）起一直是最好的保证，直到 1995 年。

【检查 1】一张 4-环（正方形，4 条边）的最大切是几？随机涂色期望切几条？

### 7.2.3 另一个主角：顶点覆盖（Vertex Cover）

在图里选最少的点，使每条边至少有一个端点被选中（想象在路口放哨兵，看住所有路）。

一个 1970 年代就有的简单算法：反复找一条两端都没选的边，**把两端都选上**。最优解至少要选这条边的一端，而我们选了两端，所以最多是最优的 **2 倍**。这就是 **2-近似**。

50 年来，没人能做到"1.99 倍"。

## 7.3 Goemans–Williamson：把顶点变成向量

### 7.3.1 松弛：先解一个更宽松的问题

Max-Cut 难在每个点只能取两个值（黑 = +1，白 = −1）。一条边 (i, j) 被切，当且仅当 xᵢ·xⱼ = −1，所以切到的边数 = Σ (1 − xᵢxⱼ)/2。

Goemans–Williamson（1995）的想法：**把每个 ±1 换成一个单位向量 vᵢ**，把乘积 xᵢxⱼ 换成内积 vᵢ·vⱼ：

```
最大化  Σ_边 (1 − vᵢ·vⱼ)/2      约束：每个 vᵢ 都是长度为 1 的向量
```

这叫**半定规划（SDP）**，可以在多项式时间内（近似地）解出来。因为 ±1 是"一维单位向量"，原问题的每个解都是它的解，所以 **SDP 的最优值 ≥ 真正的最大切**。直觉上：边的两端被推得越"相反"（夹角越接近 180°）越好。

### 7.3.2 随机超平面：把向量变回黑白

解出向量以后，随机选一个过原点的平面，把空间劈成两半：在一侧的点涂黑，另一侧涂白。

关键事实：**两个夹角为 θ 的向量，被随机平面分开的概率恰好是 θ/π。** 二维里最好想：随机一条过原点的直线，落在两向量"之间"的概率就是 θ/180°。

脚本用 100 万次随机平面验证：

| 夹角 | 理论 θ/π | 模拟 |
|---|---|---|
| 90° | 0.5000 | 0.4994 |
| 120° | 0.6667 | 0.6659 |
| 150° | 0.8333 | 0.8337 |

### 7.3.3 0.878 是怎么来的

对每条边比较两个量：
- SDP 给它的"分数"：(1 − cos θ)/2；
- 取整后它真正被切的概率：θ/π。

只要对**每个**夹角，后者都至少是前者的 α 倍，整张图就至少是 SDP 值的 α 倍，也就至少是最优值的 α 倍。所以保证 = 这个比值在所有夹角上的最小值：

```
α_GW = min over θ of  (θ/π) / ((1 − cos θ)/2)  =  min  2θ / (π(1 − cos θ))
```

脚本实算（数值最小化）：

| 夹角 θ | SDP 分数 | 被切概率 | 比值 |
|---|---|---|---|
| 60° | 0.250 | 0.333 | 1.333 |
| 90° | 0.500 | 0.500 | 1.000 |
| 120° | 0.750 | 0.667 | 0.889 |
| **133.56°** | **0.845** | **0.742** | **0.8786（最小）** |
| 150° | 0.933 | 0.833 | 0.893 |
| 180° | 1.000 | 1.000 | 1.000 |

**α_GW = 0.878567…**，在 θ ≈ 133.56°（内积 ρ ≈ −0.689）处取到。这个数和 OpenAI 的 Max-Cut 论文式 (1.1) 给出的 0.878567… 一致。

### 7.3.4 一个例子：五边形

5-环的 SDP 最优解是把 5 个向量在平面上每隔 144°（= 4π/5）摆一个。脚本实算：
- SDP 值 = 5 × (1 − cos 144°)/2 = **4.5225**；
- 真正的最大切 = 4；
- 随机平面期望切 5 × 144/180 = **4.000**。

所以在五边形上 SDP 值比真实最优高了一截（4/4.5225 = 0.8845）。这种"SDP 过于乐观"的差距叫**整性间隙**（integrality gap）。Feige–Schechtman（2002）构造了让这个比值无限逼近 0.878 的图，所以**单靠这个 SDP 加任何取整方法都不可能超过 0.878**。但这只说明"这一个算法"到头了，不说明"所有算法"到头了。

## 7.4 近似也可能是难的：PCP 定理

### 7.4.1 PCP 定理的直觉

**PCP 定理**（Arora–Safra；Arora–Lund–Motwani–Sudan–Szegedy，1992 年会议，1998 年期刊；Dinur 2007 给了组合证明）说的事情听起来像魔术：

> 任何数学证明都可以改写成一种特殊格式，使得审稿人**只随机抽看其中常数个比特**，就能以很高把握判断证明对不对：正确的证明一定通过；错误的证明，无论怎么写，都会以至少一半的概率被抓住。

### 7.4.2 为什么它和"近似"有关

把 PCP 换个说法：存在一个从 3SAT 出发的归约，得到一个约束系统，满足
- 原公式可满足 ⇒ 约束系统**全部**能满足；
- 原公式不可满足 ⇒ 约束系统**最多**满足一个固定比例 s < 1。

这叫**间隙**（gap）。现在假如有一个算法能保证 α > s 的近似比，就能拿它区分这两种情况，也就能解 3SAT。所以：**有间隙 ⇒ 近似到间隙之上是 NP 难的。**

接下来几十年的游戏，就是把这个间隙做得越来越"尖锐"，让它恰好卡在已知算法的位置上。

### 7.4.3 Max-Cut 的缺口

Håstad（2001，*JACM*）加上 Trevisan–Sorkin–Sudan–Williamson 的"小部件"，证明：**Max-Cut 近似到 16/17 ≈ 0.941 以上是 NP 难的。**

于是：

```
0.5 ─────────── 0.878 ░░░░░░░░░ 0.941 ──── 1.0
     随机涂色      GW 算法  ?未知?   NP 难
```

**0.878 和 0.941 之间是谁？** 更好的算法，还是更强的难度证明？这就是 UGC 要回答的。

## 7.5 Unique Games 是什么

### 7.5.1 标签游戏

一个**标签约束系统**：
- 一张图；
- 一个"字母表"：每个顶点要从 {0, 1, …, k−1} 里选一个标签；
- 每条边带一个约束，规定两端的标签怎样才算"相容"。

目标：选标签，使满足的约束比例（叫这个实例的**值**）尽量高。

PCP 定理的标准产物"Label Cover"就是这种形式，只是约束是"多对一"的：一端定了，另一端有好几个选择。

### 7.5.2 "唯一"：一端定了，另一端唯一确定

**Unique Game**：每条边的约束是一个**置换**（一一对应）。一端选了某个标签，另一端**恰好只有一个**标签能满足这条边。

最常见、也是这一章用的例子：**模 k 的差分方程**

```
x_i − x_j ≡ c   (mod k)
```

给定 x_j，x_i 就被唯一确定为 x_j + c。（OpenAI 论文用的是"平移约束" a(v) = a(u) + c，只是把模 k 的数换成了 0/1 向量的按位异或，本质一样。）

### 7.5.3 手算：三角形，模 3

三个变量 a, b, c，标签 {0, 1, 2}：

**实例 A**：b − a ≡ 1，c − b ≡ 1，a − c ≡ 1（mod 3）。
绕一圈相加：0 ≡ 3 ≡ 0，没有矛盾。取 a = 0，传播得 b = 1，c = 2，检查 a − c = −2 ≡ 1 ✓。**全部满足，值 = 1。**

**实例 B**：把最后一条改成 a − c ≡ 2。
绕一圈相加：0 ≡ 1 + 1 + 2 = 4 ≡ 1，矛盾。所以三条不可能同时成立，但去掉任何一条就能满足。**值 = 2/3。**（脚本暴力枚举 27 种标签确认。）

一般规律：**在一个环上，把约束常数绕一圈加起来，如果不是 0（mod k），这个环上至少有一条约束必然被违反。**

【检查 2】四个变量 x₀…x₃，模 5，约束：x₁−x₀≡2，x₂−x₁≡3，x₃−x₂≡1，x₀−x₃≡4，x₂−x₀≡0。全部能满足吗？如果把最后一条改成 x₂−x₀≡1 呢？

### 7.5.4 为什么"完全能满足"的很容易

如果一个 unique game 能被**全部**满足，有一个简单的多项式时间算法：

1. 在每个连通块里任选一个点，试它的 k 个标签之一；
2. 沿着边传播：每条边都唯一决定邻居的标签；
3. 遇到矛盾就换下一个起始标签；k 个都试过还不行，就说明不能全部满足。

每次尝试只要扫一遍图，总共 k 次。对比一下暴力枚举：100 个变量、模 3，要试 3¹⁰⁰ ≈ 10⁴⁷·⁷ 种（脚本实算）。

这和 3SAT 完全不同：3SAT 就算"全部能满足"也很难找到解。**所以 UGC 不能谈"可满足 vs 不可满足"，只能谈"几乎可满足 vs 远远不可满足"。** 这就是 UGC 里 1 − ε 的由来。

### 7.5.5 为什么"几乎能满足"可能很难

一旦有少量约束是"错的"，传播就会把错误带到很远。脚本做了一个实验：2000 个点、每点平均 6 条边的随机图，模 7；先埋一个标准答案，再随机篡改一部分约束；然后从随机起点用传播法（广度优先）定标签，试 20 个起点：

| 篡改比例 | 埋入答案的值 | 传播法平均值 | 传播法最好值 |
|---|---|---|---|
| 0% | 1.000 | 1.000 | 1.000 |
| 1% | 0.990 | 0.958 | 0.982 |
| 5% | 0.947 | 0.728 | 0.845 |
| 10% | 0.901 | 0.610 | 0.709 |

（脚本实算；随机图里有极少数孤立点，标签默认取 0，对结论无影响。）

原因：一个点的标签是沿一条路径从起点"传"过来的，路径上只要经过一条坏边，后面整片都会错位。

**要诚实地说明**：这个实验只说明"传播法"不行，不说明问题本身难。对这种**随机**的带噪实例，更聪明的算法（比如 SDP）其实能做得很好。UGC 说的是：**存在**一些精心构造的实例，任何多项式时间算法都分不清"它是 99% 可满足"还是"它只有 1% 可满足"。

### 7.5.6 UGC 的精确陈述

> **唯一博弈猜想（Khot 2002）**：对任意 ε > 0 和 δ > 0，都存在一个字母表大小 k，使得对字母表为 k 的 unique game，区分下面两种情况是 NP 难的：
> - YES：值 ≥ 1 − ε（几乎全部能满足）；
> - NO：值 ≤ δ（几乎全部不能满足）。

注意**量词顺序**：先给定 ε、δ，**再**选字母表大小 k。如果反过来允许 k 随实例增长，就有已知的算法能解（Charikar–Makarychev–Makarychev 2006 的 SDP 算法能拿到约 1 − O(√(ε log k))，k 小时就很好）。OpenAI 论文第 1.2 节专门讨论了这一点。

## 7.6 为什么 UGC 重要：一个猜想管一大片

UGC 的魅力在于：假设它成立，很多问题的**精确**近似极限就能被算出来，而且往往**恰好等于某个已知算法**。

| 问题 | 最好的算法 | 无条件 NP 难（2026 年前） | 假设 UGC |
|---|---|---|---|
| Max-Cut | 0.878（GW 1995） | 16/17 ≈ 0.941（Håstad 2001） | **0.878 就是极限**（KKMO 2004/07） |
| 顶点覆盖 | 2 | √2 ≈ 1.414（KMS 2018） | **2 就是极限**（Khot–Regev 2003/08） |
| 所有约束满足问题（CSP） | 基本 SDP + 取整 | 各不相同 | **基本 SDP 就是最优算法**（Raghavendra 2008） |

几个关键结果：

- **KKMO**（Khot–Kindler–Mossel–O'Donnell，FOCS 2004，*SICOMP* 2007）：UGC ⇒ Max-Cut 超过 α_GW 是 NP 难的。他们需要的一个概率论命题"多数最稳定"（Majority Is Stablest）后来由 Mossel–O'Donnell–Oleszkiewicz（2005，*Annals* 2010）证明。GW 算法里那个奇怪的 133.56° 夹角，恰好对应难度归约里的"噪声"参数，算法和难度在同一个数上相遇。
- **Khot–Regev**（CCC 2003，*JCSS* 2008）：UGC ⇒ 顶点覆盖做不到 2 − ε。那个 1970 年代"选两端"的笨算法就是最优的。
- **Raghavendra**（STOC 2008）：UGC ⇒ 对**每一个** CSP，同一个通用的 SDP 算法就是最优的多项式时间近似算法。一个算法加一个猜想，决定了一整类问题。

这就是为什么 UGC 被说成"近似算法领域的地图"。Khot 因此获得 2014 年 Nevanlinna 奖。

## 7.7 24 年的拉锯：支持与怀疑

### 7.7.1 怀疑：亚指数时间算法（2010）

Arora–Barak–Steurer（FOCS 2010，*JACM* 2015）给出一个算法：对字母表为 k、n 个变量、值 ≥ 1 − ε^c 的 unique game（c 是某个固定常数），能在 **exp(k·n^ε)** 时间内找到满足 1 − ε 的标签。

这为什么让人怀疑 UGC？因为一般相信 3SAT 需要接近 2ⁿ 的时间，而 UG 只需要 2 的"n 的小次方"。脚本实算对比：

| n | 3ⁿ（暴力） | 2^(n^0.1) | 2^(n^(1/3)) | n³ |
|---|---|---|---|---|
| 100 | 10^47.7 | 3 | 10^1.4 | 10⁶ |
| 1,000 | 10^477 | 4.0 | 10^3.0 | 10⁹ |
| 1,000,000 | 10^477121 | 15.8 | 10^30.1 | 10¹⁸ |

如果 UGC 成立，从 3SAT 到 UG 的归约必须把实例**放大**到很大的多项式规模（否则 3SAT 也会有亚指数算法）。这不矛盾，但说明 UG 即使难，也"难得不彻底"。一部分研究者因此倾向于相信 UGC 是假的。

### 7.7.2 支持：2-to-2 定理（2018）

**2-to-2 约束**：比 unique 宽松一点，一端定了，另一端有 2 个可选标签。Khot–Minzer–Safra 及 Dinur–Khot–Kindler–Minzer–Safra 在 2017–2018 年的一系列工作（最后一块是 KMS FOCS 2018 关于 Grassmann 图扩张性的定理）证明：**几乎可满足的 2-to-2 游戏是 NP 难的。**

推论：
- **完备度约 1/2** 的 unique game 是 NP 难的：区分"值 ≥ 1/2 − ε"和"值 ≤ δ"。被称为"半个 UGC"。
- 顶点覆盖 √2 − ε 是 NP 难的。

剩下的难点：把完备度从 1/2 推到 1 − ε。OpenAI 论文第 1.3 节也说："Obtaining Unique Games completeness arbitrarily close to one was a separate problem."

### 7.7.3 2026 年 9 月：一场赛跑

据 Quanta（2026-10-07）报道，MIT 的 Dor Minzer 和学生 Yumou Fei、Shuo Wang 听到 OpenAI 即将发布 UGC 证明的传闻后，在 2026-09-14 抢先贴出了 Khot 2-to-1 猜想的一个 4-to-1 变体的证明。O'Donnell 评价："They solved the problem in the old-fashioned way, with their minds, and wrote it with their own fingers." [R]

## 7.8 OpenAI 声称了什么

### 7.8.1 主结果

论文 *The Unique Games Theorem*（2026-09-23，58 页，作者署名 "OpenAI"）的摘要：

> "We prove the Unique Games Conjecture. For every fixed ε, δ ∈ (0, 1/2), we give a deterministic polynomial-time reduction from 3SAT to Unique Games over a fixed finite alphabet, with completeness at least 1 − ε and soundness at most δ." [P]

翻译：**对任何固定的 ε、δ，有一个确定性的多项式时间归约，把 3SAT 翻译成字母表固定的 unique game：可满足的公式变成值 ≥ 1 − ε 的实例，不可满足的变成值 ≤ δ 的实例。** 这正是§7.5.6 UGC 的陈述。

定理 1.1 还说了更强的形式：字母表是 0/1 向量空间 F₂ˢ，每条约束都是平移；图是简单、二部、无权的。论文说这是 UGC 的一个已知等价形式（引用 KKMO），所以"更强"不是"偷换"。

### 7.8.2 同一家族（family 102）的其他论文

| 论文 | 页数 | 结论 |
|---|---|---|
| A Direct Proof of Optimal Max-Cut Hardness | 38 | Max-Cut 超过 α_GW 是 NP 难的 |
| The Factor-Two Hardness Threshold for Vertex Cover | 25 | 顶点覆盖做不到任何 < 2 的常数倍 |
| Constant-factor hardness of Min-UnCut | — | 任意常数倍都是 NP 难的 |
| Constant-factor hardness of directed feedback vertex set | — | 任意常数倍都是 NP 难的 |

仓库 CONTENTS.md 说这 4 篇是**独立的直接归约**，"use established PCP and Label Cover hardness results"，不依赖 UGC 论文。也就是说，就算 UGC 那篇有错，Max-Cut 0.878 和顶点覆盖 2 这两个最有名的推论还有一条独立的路。复杂性理论学者 Dana Moshkovitz 的评论（Aaronson 在 "The Mathocalypse" 评论 #2 里转贴，开头写明 "Additional commentary from Dana on the UGC proof"）说："The Unique Games Conjecture is true, though it wasn't really needed for the proof of its most famous corollaries"，括号里举的例子是 Max-Cut 和其他约束满足问题的最优近似难度 [R]。指的就是这 4 篇直接归约。

另外，**family 105**（*Perfect completeness for 2-to-1 games*）声称证明了 Khot 的 2-to-1 猜想（完美完备度版本）。UGC 论文的脚注 1 说它"不是本证明的输入"。

### 7.8.3 方法的直觉（只读了引言，以下是简化版）

1. **起点**：Håstad 的"几乎可满足的奇偶方程组"难度结果（每个方程 x + y + z ≡ b mod 2）。
2. **2-to-2 那条路为什么卡在 1/2**：Barak–Kothari–Steurer 的"矩阵短码"里，诚实的证明在一次随机的秩一扰动下，答案保持不变的概率是 (1 + 2^(−ℓ))/2，也就是约 1/2。所以完备度只能做到 1/2。
3. **关键的新想法：换一种噪声**。论文构造了一个非线性的"编码器" C 和一种特殊噪声 μ：诚实答案在这种噪声下几乎不变（变化概率 ≤ 任意小的 p），但任何"作弊"的、高秩的线性观察仍然以至少 1/8 的概率察觉到噪声。可以类比成：设计一种抖动，让正确的读数几乎不受影响，却能让伪造的读数露馅。这样完备度就能推到 1 − ε，同时保留 2-to-2 那套用于可靠性的结构工具。
4. **可靠性（不可满足的公式值 ≤ δ）**：沿用 KMS 2018 的 Grassmann 扩张定理（以"逆短码定理"的形式）提取出一个策略，再用并行重复（Dinur–Steurer 2014）把成功率压到 exp(−c·k^(1/3))，从而推出矛盾。
5. **收尾**：去掉权重和重复边，得到简单、无权、二部的实例。

## 7.9 它被核实到什么程度

### 7.9.1 Lean 陈述：比准黎曼猜想长得多，但仍然可读

准黎曼猜想（§4）的 Lean 陈述只有一行，因为 Mathlib 里已经有 ζ 函数。UGC 不同：Mathlib 里**没有** "unique game"、"3SAT 编码" 或 "多项式时间归约到图" 的现成定义，所以挑战文件 `ComparatorChallenges/UniqueGamesTheorem.lean`（239 行）要自己把这些都定义出来。核心定理（完整名字 `OAI.UniqueGamesTheorem.theorem11`；以下是我读 Lean 源码后的翻译 [P]）：

```lean
theorem theorem11 (ε δ : ℝ)
    (hε : 0 < ε) (hεhalf : ε < 1 / 2)
    (hδ : 0 < δ) (hδhalf : δ < 1 / 2) :
    Nonempty (Explicit.MachineOutputContract.BinaryGapReduction ε δ)
```

逐词翻译：
- `(ε δ : ℝ)`：ε 和 δ 是实数。
- `hε`、`hδ`：假设 0 < ε < 1/2，0 < δ < 1/2。
- `Nonempty (BinaryGapReduction ε δ)`：结论是"**存在**一个满足下面所有条件的归约"。

`BinaryGapReduction ε δ` 是一个结构体，要求同时给出：

| 字段 | 意思 |
|---|---|
| `alphabet`、`dimension`、`coordinates` | 字母表大小 k ≥ 2，并且等同于 F₂ˢ（0/1 向量） |
| `construct : List Bool → Instance alphabet` | 输入一串比特（3SAT 公式的编码），输出一个 unique game |
| `simpleBipartite` | 输出的图是简单二部图 |
| `translations` | 每条约束都是平移 a(v) = a(u) + c |
| `computation : Turing.TM2ComputableInPolyTime …` | `construct` 能被 Mathlib 里的多带图灵机在多项式时间内算出 |
| `finiteAlphabet` | 图灵机的带字母表有限 |
| `completeness` | 输入是可满足公式 ⇒ 存在标签，满足比例 ≥ 1 − ε |
| `soundness` | 输入不是可满足公式 ⇒ 所有标签，满足比例 ≤ δ |

几个值得注意的细节：
- 置换用"正表 + 逆表 + 两条互逆证明"表示，所以确实是一一对应。
- 重复边按出现次数计数，没有隐藏权重。
- 输入串如果根本解析不出公式，算作"不可满足"，归约也必须输出值 ≤ δ 的实例。这是更苛刻的要求，不是放水。
- 限制 ε, δ < 1/2 不影响结论：UGC 关心的正是小的 ε、δ。
- 完备度写成 ≥ 1 − ε 而不是 = 1，这是对的：§7.5.4 说过，完全可满足的情况是容易的。

**我的判断：这是 UGC 的忠实编码，而且是更强的形式。** 一个需要读者自己补的外部事实：定理说的是"从 3SAT 归约过来"，"所以是 NP 难的"还需要 Cook–Levin 定理（3SAT 是 NP 完全的），这一步不在这个陈述里，但它是教科书结果，没有争议。

## 7.10 如果为真，意味着什么（以及不意味着什么）

### 7.10.1 对理论计算机科学

1. **一大批条件性结论变成定理**：Max-Cut 的 0.878、顶点覆盖的 2、Raghavendra 的"SDP 对所有 CSP 最优"等。过去 20 年写着"假设 UGC，则……"的数以百计的论文，前提被拿掉了。
2. **近似算法的地图基本画完了**：对很多问题，"能做到"和"做不到"之间的缺口闭合了。GW 1995 年的算法被证明是最优的。
3. **亚指数算法不再是反例**：UGC 为真和 ABS 的 exp(n^ε) 算法并存。这意味着 3SAT 到 UG 的归约必然产生规模极大的多项式（论文说多项式的次数和常数只依赖 ε、δ，但没给具体数）。

### 7.10.2 它不意味着什么

- **不解决 P vs NP**。所有结论都是"X 是 NP 难的"，也就是"除非 P = NP，否则 X 做不到"。如果明天有人证明 P = NP，这些难度结论全部作废。Fortnow 在同一篇博客里也说这些结果没有让我们更接近解决 P vs NP [R]。
- **不影响实际工程**。工业界做图划分、聚类用的是启发式算法，在真实数据上往往远好于最坏情况的 0.878。UGC 说的是**最坏情况**下的**保证**。
- **不推翻任何已知算法**。它只证明"已有的算法不能再改进了"。

### 7.10.3 对 AI

- 这是 OpenAI 这批结果里**最接近 AI 研究者日常**的一个：它的核心对象（SDP 松弛、随机取整、PCP 风格的验证）都是计算机科学的基本工具。
- 一个联想（**我的推测，不是已有结论**）：辩论式可扩展监督（Irving–Christiano–Amodei 2018，arXiv:1805.00899）的复杂性理论底子是交互式证明和 PCP："一个弱验证者能否只看少量信息，就判断强证明者的论证"。UGC 刻画的是"有一点点噪声就无法高效区分"的边界。对"弱监督者 + 强模型"的协议设计来说，它提示**完美一致**和**几乎一致**之间可能存在本质的计算难度差异。
- 和 §4 准黎曼猜想一样，这里出现了"58 页难读的论文 + 18.7 万行 Lean"的组合。信任的瓶颈从"证明对不对"转移到了"**陈述有没有编码对**"，这正是§7.9.1 在做的规格审查（spec review）。
